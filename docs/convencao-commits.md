# Convenção de Commits -- Curso JavaScript/TypeScript (Udemy)

## Convenção

  Tipo         Quando usar
  ------------ ----------------------------------------------
  `chore`      Configurações, organização e estrutura
  `docs`       README, documentação e anotações
  `feat`       Novas funcionalidades, exercícios e projetos
  `refactor`   Refatoração sem alterar comportamento
  `fix`        Correções de bugs
  `test`       Testes automatizados
