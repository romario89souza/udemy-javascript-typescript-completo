# JavaScript e TypeScript - O Curso Completo

Repositório destinado aos estudos do curso **JavaScript, do Zero a Programador Avançado (2026)** da Udemy.

Cada pasta na raiz corresponde a uma seção do curso, numerada na mesma ordem do índice de aulas.
Dentro de cada seção há um `README.md` com o checklist de todas as aulas daquela seção, e
subpastas para os projetos e exercícios práticos que acompanham as aulas em vídeo.
